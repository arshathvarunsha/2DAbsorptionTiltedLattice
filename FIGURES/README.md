#### FIGURES USED IN RESULTS

This folder contains all the raw data and Jupyter notebooks required to reproduce the figures presented in the paper. Each subfolder includes:


1.Raw Data –------------------------------------------------ the original datasets used for analysis.

2.Jupyter Notebook –----------------------------------------- a well-commented and clearly explained notebook to generate the corresponding plots.

3.Figures –-------------------------------------------------- the final figures produced from the analysis.



All Jupyter notebooks are thoroughly documented for ease of use. If you have any questions or need clarification, please feel free to contact us.
